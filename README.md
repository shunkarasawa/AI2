# 静か — 瞑想と呼吸のアプリ

オフラインで完全に動く瞑想 PWA。呼吸ガイド、瞑想タイマー、環境音、継続記録。
アカウント不要、通信なし、音源ファイルなし。

```
npm install
npm run dev           # http://localhost:5173
npm run dev -- --host # 同じ Wi-Fi のスマホから開く
npm run build         # 型チェック + dist/ を生成
npm run preview       # ビルド結果を確認
npm run build:single  # dist/shizuka-single.html（1ファイルで完結する版）
```

## 何ができるか

| 機能 | 中身 |
|---|---|
| **呼吸ガイド** | 5-5 コヒーレント / 4-6 / ボックス 4-4-4-4 / 4-7-8 / 6-10 の5種。円の伸縮＋残り秒数＋振動で誘導 |
| **タイマー** | 1〜60分。開始のボウル、終了のゴング、途中のチャイム（1〜10分ごと） |
| **環境音** | 雨・波・小川・夜の森・ホワイトノイズ・ブラウンノイズ・ドローンの7種。ホーム画面から試聴できる |
| **記録** | 連続日数、最長連続、通算回数と時間、5か月分のヒートマップ、週ごとの合計、履歴 |
| **その他** | 明暗テーマ、セッション中の画面スリープ抑止、JSON の書き出し・読み込み |

## 設計上の判断

### 音はすべてリアルタイム合成する

`src/audio/` に音源ファイルは1つもない。ベルも環境音も Web Audio で毎回作っている。

- **著作権の問題が発生しない** — 素材のライセンスを追跡する必要がない
- **バンドルが軽い** — JS + CSS で約 250KB。音源を持てば数十MBになる
- **ループの継ぎ目がない** — 何十分鳴らしても同じ波形が繰り返さない
- **オフラインで完全に動く** — 機内モードでも鳴る

作り方:

- **ベル** (`audio/bell.ts`) — 金属の打楽器は倍音が整数比にならない。この非整数比が「金属の響き」の正体なので、比率は 1 : 2.41 : 3.85 … のような値にしてある。さらに各パーシャルを ±0.3Hz ほどずらした2本で鳴らし、うなり（beating）で実際のボウルのような揺れを作っている。
- **環境音** (`audio/ambient.ts`) — 「ノイズをフィルタで削って、ゆっくり揺らす」。揺らぎの周期（0.037Hz, 0.019Hz, 0.011Hz …）は互いに素にして、規則性が耳につかないようにしている。波は18秒周期のうねりに、泡だけ 1.06 倍の周期をあてて少しずつズレさせている。
- **ノイズ** (`audio/noise.ts`) — ホワイト／ピンク（Paul Kellet 近似）／ブラウン。8秒のバッファをループさせるが、末尾に先頭 50ms をクロスフェードし、再生側の `loopStart` を 50ms にずらすことで継ぎ目のクリックを消している。

### 経過時間は `performance.now()` の差分で出す

`setInterval` を数える方式はタブが裏に回った瞬間にずれる。差分方式なら復帰時に正しい位置へ戻る。
裏にいる間に過ぎたベルは鳴らさない（戻った瞬間に連打されないように、2秒以上前のものは飛ばす）。
一時停止していた時間は「座っていた時間」に含めない。

### 60fps の値は React の state に入れない

円の大きさは毎フレーム変わる。これを state にすると毎フレーム再レンダリングが走る。
`useSession` は `onFrame` コールバックを渡し、呼び出し側が CSS 変数と `stroke-dashoffset` を直接書く。
state を更新するのは**表示される整数が変わったときだけ**（残り秒数、区間名、呼吸回数）。

### 文字を円の中に置かない

円は伸縮するので、中央の文字の背景が「濃い円の上」と「暗い背景の上」を行き来する。
どちらでも十分な明度差が取れる文字色は存在しない。だから読み取り部分は円の外（下）にある。

### グラフの色

ヒートマップは連続量なので**単色ランプ**（薄い→濃いティール5段階）。虹色は使わない。
週別グラフは系列が1本なので凡例を置かず、数値ラベルは今週だけに付けて、他は hover と「数値で見る」の表で読む。
薄い段は背景との差が小さいので、マスは1つずつ focus でき、読み上げ用の文を持たせている。

## データの扱い

記録は `localStorage` にだけ保存する（`shizuka.sessions.v1` / `shizuka.settings.v1` / `shizuka.config.v1`）。
サーバーはなく、通信もしない。端末を変えるときは設定画面から JSON を書き出す。
30秒未満のセッションは記録しない（誤タップや音の確認を残さないため）。

## 構成

```
src/
  audio/      context.ts / noise.ts / bell.ts / ambient.ts   音の合成
  hooks/      useSession.ts                                  進行の管理（タイマー・位相・ベル）
  lib/        patterns.ts / storage.ts / stats.ts / time.ts / haptics.ts
  components/ BreathOrb / Heatmap / WeeklyBars / ChartTip / TabBar / ui / icons
  screens/    Home / Session / Stats / Settings
scripts/
  generate-icons.mjs   PNG アイコンを生成（画像ライブラリを使わず zlib で PNG を組み立てる）
```

React 19 + TypeScript + Vite。ランタイム依存は react / react-dom だけ。
UI ライブラリ、CSS フレームワーク、アイコンライブラリ、状態管理ライブラリは入れていない。

## ホーム画面に追加する

`npm run build` した `dist/` を HTTPS で配信すれば、そのままインストールできる PWA になる。
Service Worker で全アセットを事前キャッシュするので、2回目以降はオフラインで起動する。
